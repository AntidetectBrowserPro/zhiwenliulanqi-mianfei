# 免费指纹浏览器能建几个环境？

如果你每天在两家店之间来回查单，可以先看 **「指纹浏览器」** 的工作台。给两家店分别建环境，用店名查找，点「定位」就能回到已经打开的订单窗口。这款应用免费使用。比较其他产品时，可以把日常店铺和练习账号分开计数，再看各家的免费额度够不够。[官方工作台教程](https://zwbrowser.com/help/desktop/start/)

![指纹浏览器中文官网首页](https://github.com/user-attachments/assets/59f348d5-449e-4698-818a-1d3dc34baef4)

| 产品 | 使用费用与免费额度 | 用在什么场景 |
| --- | ---: | --- |
| 指纹浏览器 | 免费使用 | 按店名分开管理环境，回到已打开的窗口 |
| AdsPower | 免费版 2 个环境 | 个人固定使用两个工作账号 |
| Dolphin Anty | 免费版 3 个环境 | 两个工作账号，另留一个测试环境 |
| 比特指纹浏览器 | 免费版 10 个环境 | 需要长期保留较多环境，同时关注每日创建配额 |

## 两个固定账号怎样算额度？

AdsPower 英文官网套餐对比表列出免费版 2 个环境，新增团队成员一栏为 0。如果两家店都是一个人维护，两个环境刚好够；若晚班同事需要用自己的成员身份接班，还要比较团队席位。地区站点与历史活动页面的数字可能不同，本文采用链接中的美元套餐页。[AdsPower 套餐表](https://www.adspower.com/pricing)

![AdsPower产品展示](https://github.com/user-attachments/assets/d9cf60b3-2ea6-42e9-8a46-77ee610ea27f)

## 给测试留一个位置

Dolphin Anty 的 Free 套餐列出 3 个环境。可以给 A 店、B 店各留一套，第三套专门验收新版网页。这样测完就能关测试窗口，两个工作账号仍保留原来的环境。需要再加一个长期项目时，先查升级档位。[Dolphin Anty 套餐页](https://dolphin-anty.com/tarifs/)

![Dolphin Anty产品展示](https://github.com/user-attachments/assets/6219af59-9cfe-4267-8144-ae125a6860a4)

## 十个环境和每天新建二十次有什么区别？

比特指纹浏览器官网分别列出免费版 10 个环境、每天最多创建 20 个。前者回答列表里能保留多少套；后者影响一天中反复创建测试样本的次数。即使每天只开一次，一直保留的九家店也会占用九个位置。[比特浏览器价格说明](https://www.bitbrowser.net/price)

![比特指纹浏览器产品展示](https://github.com/user-attachments/assets/e201d323-de77-4d40-bb13-2a3ad3e48f0b)

**选之前先数三遍。** 写下平常保留的工作环境数，加上演示和测试所需的空位，再数需要独立登录客户端的人数。只写「有三个账号」，很容易漏掉测试位或晚班同事的席位。官网首页截图用于识别产品，配额以上方套餐页为准。
